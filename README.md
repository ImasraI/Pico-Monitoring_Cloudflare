# DANTO

وب‌اپ پایش درمان ارتودنسی با حساب‌های جداگانهٔ پزشک و بیمار.

## راه‌اندازی

```sh
npm ci
npm run db:generate
npm run build
npm start
```

پایگاه داده D1 و فایل‌های اسکن در R2 نگهداری می‌شوند. ساختار داده در `db/schema.ts` و مهاجرت‌های SQL در `drizzle/` قرار دارند. مهاجرت‌ها هنگام انتشار Site اعمال می‌شوند. برای اجرای محلی، مهاجرت تولیدشده باید پیش از شروع برنامه روی D1 محلی اعمال شود.

متغیر محرمانهٔ `DANTO_SETUP_KEY` در تنظیمات محیط اجرای Site ثبت می‌شود. پزشک با این کد، نام، ایمیل و رمز عبور حداقل ۱۲ نویسه حساب می‌سازد.

پزشک در «افزودن بیمار» فقط نام کامل، شماره موبایل، کد ملی ۱۰ رقمی و تاریخ تولد را ثبت می‌کند. حساب بیمار همان لحظه فعال می‌شود؛ نام کاربری شماره موبایل و رمز اولیه کد ملی است. رمز با نمک اختصاصی و PBKDF2 ذخیره می‌شود. ارقام فارسی و عربی پذیرفته می‌شوند و صفر ابتدای کد ملی حفظ می‌شود. اطلاعات ورود در رسید ثبت بیمار نمایش داده می‌شود؛ برنامه خودش ایمیل یا پیامک ارسال نمی‌کند. حساب‌ها و دعوت‌نامه‌های قبلی همچنان قابل استفاده‌اند.

بیمار در اولین ورود فرم اطلاعات تکمیلی را می‌بیند. مشخصات تکمیلی، سوابق و مدارک اولیه با توضیح در پروندهٔ پزشک ثبت می‌شوند. پزشک می‌تواند مشخصات را ویرایش کند و اطلاعات بالینی، فایل‌های طرح درمان و رویدادهای مسیر درمان را جداگانه ثبت کند؛ این موارد هنگام ایجاد حساب می‌توانند خالی بمانند. بیمار اجازهٔ تغییر مشخصات اولیه، اطلاعات بالینی یا فایل‌های طرح درمان را ندارد. یادداشت‌های خصوصی پزشک در حساب بیمار نمایش داده نمی‌شوند. بیمار فقط می‌تواند فایل‌هایی را که خودش بارگذاری کرده حذف کند.

ویرایش شماره موبایل توسط پزشک نام کاربری را به‌روز می‌کند؛ ویرایش کد ملی رمز فعلی را تغییر نمی‌دهد. حساب‌های قبلی با ایمیل و رمز قبلی وارد می‌شوند.

پیام‌ها و اعلان‌ها داخل وب‌اپ ثبت می‌شوند. اعلان هنگام بسته‌بودن مرورگر، ایمیل یا پیامک در این نسخه وجود ندارد. پیام فوری تنها در پنل پزشک برجسته می‌شود و جایگزین خدمات اورژانسی نیست.
