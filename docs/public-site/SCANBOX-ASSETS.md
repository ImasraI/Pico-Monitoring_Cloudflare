# ScanBox temporary image assets

Only `/scanbox` consumes these assets. All images were generated with the built-in ImageGen tool. They are temporary concept images, not verified product photographs or patient records. The clinical views show simulated dental models, not treatment results.

Replace files under `public/assets/scanbox/` using the same filenames and aspect ratio. No component or layout change is needed. Update the temporary captions and Persian alt text only after approved real photos are supplied. Product images are 1024 × 1024; clinical images are 640 × 640. Files use optimized WebP.
